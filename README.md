## Contributing

Contributions are welcome!

Please submit open-source projects that provide similar functionality to existing commercial software. See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines.

- Include the official project repository or website.
- Ensure the project is publicly accessible and licensed under an open-source license.
- Prefer actively maintained projects.
- Distinguish between complete replacements and partial alternatives.
- Avoid duplicate entries.
